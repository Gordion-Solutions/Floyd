# Floyd

Floyd is an open-source MC/DC (Modified Condition/Decision Coverage) engine for Rust, aimed at safety-critical and regulated-industry use cases (DO-178C, ISO 26262, IEC 61508). This crate currently reserves the name; the engine — MIR/HIR decision decomposition, masking analysis, condition independence proofs, and a `cargo floyd` developer workflow — is under active development. Public releases and documentation will follow as Phase 0 and Phase 1 milestones land.
